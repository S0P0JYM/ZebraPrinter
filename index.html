Troubleshooting & Notes
  • QLn printers can speak ZPL or CPCL. Set the language on the printer menu, or send the proper setup command. If your unit is set to CPCL and you send ZPL, nothing will print.
  • Use the correct print width in dots (for 2″ @ 203dpi, 406 is exact; many labels fit at 384 dots). A too‑wide width will clip the right edge.
  • USB/Bluetooth printing from the browser depends on Zebra Browser Print. Install it for Windows/macOS and keep the tray app running.
  • If you see “not loaded”, the page couldn’t load the Browser Print JS from http://localhost:9101/. Start the service and reload.
